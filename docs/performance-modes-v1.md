# 三档性能与画质策略

实现记录 · 2026-09-08 · Android 1.2 内容候选版

| 模式 | 支持游戏的 Canvas DPR 上限 | 装饰效果 |
| --- | --- | --- |
| 省电 `eco` | 1 | 去掉精灵与水瓶投影、外层背景模糊、列表装饰阴影和指定循环提示动画 |
| 普通 `normal`，默认 | 2 | 保留现有装饰 |
| 游戏 `game` | 3 | 保留现有装饰，使用更高画布精度 |

实际 DPR 不超过设备原生值。只有原本按设备 DPR 创建画布的泡泡龙和 1010 方块本次接入；其他固定逻辑分辨率的游戏、弹球内嵌引擎的画布不被强行缩放。三档不更改系统屏幕刷新率、CPU 设置、全局 `requestAnimationFrame`、定时器、游戏步进或物理速度，也没有 30 FPS 帧率限制。

设置位于“设置 → 性能与画质”，保存在 `wanba_performance_v1`。装饰效果当场生效，画布精度在下一次进入游戏时采用。设置不改变游戏存档结构。界面文案覆盖简繁中、英文、日文、韩文。

实现入口为 `standalone/performance.js`，主要接口是 `initPerformance(window)`、`getCanvasPixelRatio(window)`、`setPerformanceMode(mode,window)` 和 `mountPerformancePicker(container)`。模式改变发出 `wanba-performance-change`，不伪造 `resize` 或改写浏览器 API。重复挂载不重复添加样式或控件；存储不可用时仍可使用默认普通模式。

## 泡泡龙专项修复

真机 content1 的无操作基线显示：DPR 3，Canvas 1026×1386（约142万像素），30秒约12.47次 rAF/秒，P95间隔约100ms；同时50ms定时器的额外延迟P95约2ms。该结果支持优先减少重复绘制和高分辨率纹理开销，不能直接证明具体 GPU 根因或电量降幅。原始记录见 [真机无操作基线](evidence/android-1.2/compat-phone/performance-paopao-idle/paopao.json)。

泡泡龙现已在静止或暂停时跳过整幅重画，游戏时钟仍连续维护。发射球、掉落球及消除粒子继续逐帧绘制，并保留清除最后粒子的收尾帧。瞄准、取消瞄准、交换球、炸弹、下压和尺寸变化通过原有事件立即重画。暂停、隐藏页和退出的时间行为不变。

画布布局按 `N + 0.5` 列计算宽度，包含交错行的半格偏移；320px视口验证画布右边界在容器内，保持12列。游戏包 `game.paopao` 与 `game.game1010` 均升至 `1.0.1`。同批球体贴图和精灵缓存由美术公共模块维护，应一起按签名快照回归。

## 验证与限制

- 单元测试验证模式默认值、持久化、原生 DPR 上限、存储不可用及全局时钟未修改；三个模式下同一泡泡飞行的模拟状态完全相同。
- 原泡泡龙10/15/30/120 Hz与60 Hz运动距离回归、暂停、长间隔恢复及销毁测试通过。
- 浏览器使用 DPR 3、412px视口逐模式进入两款游戏，确认泡泡画布分别为382×516、764×1032、1146×1548，CSS尺寸均382×516；1010对应DPR也正确。
- 每档实际发送瞄准/发射输入并完成落点结算；静止700ms及暂停200ms均无Canvas重画，发射期间有多帧绘制。320px画布边界和五语言360px设置/状态均通过。
- 窄屏游戏顶栏改为信息与操作两行；五语言在320/360px下，返回、记录、暂停、重开与六位分数完整可见，无重叠；实际游戏截图见 [顶栏证据](evidence/android-1.2/game-toolbar/)。启动测试已接入新性能初始化依赖。
- 证据见 [浏览器验证目录](evidence/android-1.2/performance-modes/)。这里的 rAF 频率是调度指标，不是 GPU 实际呈现率。Canvas 像素数降低不等同于相同比例省电；最终真机三档交互与电量对比由设备回归补充。
