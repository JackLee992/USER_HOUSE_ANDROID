# 玩吧 / Nookcade 五语言覆盖记录

记录更新：2026-09-08，语言包版本 `1.0.1`。`1.0.0` 已用于首轮独立内容更新基线；本记录不代表完整海外上架验收。

## 已交付

| 语言 | 区域识别 | 显示品牌 |
| --- | --- | --- |
| 简体中文 `zh-CN` | 简体中文设备 | 玩吧 |
| 繁体中文 `zh-TW` | 繁体、香港、澳门设备 | 玩吧 |
| 英文 `en` | 英语及其他尚未支持的设备语言 | Nookcade |
| 日文 `ja` | 日本语设备 | ヌックケード |
| 韩文 `ko` | 韩国语设备 | 눅케이드 |

每个 JSON 实际包含 37 个游戏标题、37 份玩法说明、351 条静态界面文字和 56 个动态模板。`1.0.1` 比首版新增 53 条静态词条和 3 个模板，覆盖猜词元信息标签、三档性能设置、原生内容更新状态与常见失败、下载包标识及 HTTP 失败码。日英韩说明是基于实际实现编写的核心规则说明，未逐字覆盖中文长说明的全部细节。繁体文本使用 OpenCC 的台湾词汇转换并做了关键标题检查，后续仍需要母语审校。

语言包位于 `locales/{locale}.json`，通过其 `schemaVersion`、`version` 和 `locale` 独立识别。语言切换器位于设置页顶部。第一次打开按设备语言选择；手动选择保存在 `wanba_locale_v1`。非中文界面使用国际版图标；中文界面使用玩吧图标。Android 启动器名称由原生资源决定，本模块负责应用内部显示。

已翻译范围包括：单人/人机分类、37 游戏名称、首页更新/下载/回退控件、设置与主题、备份入口、版本/内核标识、游戏介绍、通用暂停/继续/重开/记录、主要道具与数字计数，以及弹球/空当接龙/消消乐的主要操作帮助。

## 验证事实

- 五种语言均在独立 Chrome 测试配置下实际切换，确认设置、列表、空当接龙说明、品牌、国际图标和存储偏好对应变化；重载后保留韩文。
- 360 CSS 像素宽度下，五语言首页及设置未出现文档级横向溢出；已查看英文、日文渲染截图。
- 英文环境逐项启动 37 个实际游戏，另测五子棋无限模式。均能暂停、保存并退出，未发现 JavaScript 异常或外部网络请求。
- 37 个初始局面中，35 个没有检测到剩余中文 DOM 文字。另两个局面的残留见下表。该检测不覆盖 Canvas 像素、用户题库或所有胜负分支。
- 语言逻辑测试覆盖区域归一化、五包键集合、动态状态、持久化、缺包回退、异步切换乱序、惯用原文回退以及文本注入边界。
- 原游戏模块迁移通过独立工厂/井字棋 AI 与暂停测试、泡泡龙 10/15/30/120 FPS 与 60 FPS 时间推进比较，以及暂停、长间隔恢复、重开销毁测试。
- `1.0.1` 在实际浏览器中逐语验证性能设置及原生 `upToDate` 状态消息，360px 页面无横向溢出。消息由测试桥提供，与 Android `ContentUpdateManager` 的原文一致；这项不替代真机更新下载验证。

首轮本地证据在 `.local/qa-i18n/result.json`、`.local/qa-i18n/{locale}-catalog.png`、`.local/qa-i18n-coverage/result.json`；`1.0.1` 设置与状态截图见 [性能及语言证据](evidence/android-1.2/performance-modes/)。证据不随游戏资源包发布。Android 真机双内核的最终安装与内容更新结果由发布回归记录补充。

## 实现与性能约束

`standalone/i18n.js` 只通过文本节点、`textContent` 及 `title`/`aria-label`/`placeholder` 写入翻译，不将语言包内容送进 `innerHTML`、`eval` 或动态函数。输入 `value`、用户猜测、题库线索与许可证正文保持原样。缺失的语言包回退到简体中文；缺失的具体文字回退到原文。

简中原生文案在初始化或语言恢复后不持续扫描 DOM。其他语言也会跳过纯数字变化，仅在出现待翻译文字或切换语言时处理，避免数字计时和动画帧反复触发整页翻译。代码没有修改全局 Canvas 绘制 API。

复现命令（仅使用独立临时浏览器配置）：

```sh
node --test tests/i18n.test.mjs tests/game-plugins.test.mjs tests/paopao-timing.test.mjs
node tests/i18n-browser.mjs 9348
node tests/performance-browser.mjs 9348
QA_LOCALE=en QA_CAPTURE_LOCALE=1 QA_OUT=.local/qa-i18n-coverage node tests/game-plugin-browser.mjs 9348
```

对应本地静态入口为 `http://127.0.0.1:8768/standalone/index.html`。最后一条仅统计当前可见 DOM 初始局面，不是完整语言覆盖率计算。
