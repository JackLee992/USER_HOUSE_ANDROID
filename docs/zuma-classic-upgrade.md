# 祖玛神庙冒险升级

本轮优先升级祖玛，保留其他 36 款游戏。游戏包与美术包均为 1.1.0；Android 1.2.1 增加系统沉浸全屏。现有 1.2.0 用户也可以通过首页更新游戏资源，获得新玩法和占满应用视口的游戏界面；隐藏 Android 状态栏和导航栏需要新 APK。

## 经典体验与实现范围

对照 [PopCap / EA 官方商店介绍](https://store.steampowered.com/app/3330/Zuma_Deluxe/)与 [Astraware 发行的移动版说明书镜像](https://tapwave.net/files/zuma/dl/Astraware%20Zuma%20for%20Palm.htm)，本轮实现石蛙发射、三颗以上相邻同色消除、换球、同色断口吸回连锁、异色断口前段等待、金色目标槽、清尾过关、三条生命、金币和四种标记珠能力。连续命中和一次发射产生的多次连锁分别统计，穿越实际珠链断口后形成消除会获得额外奖励。

六座神庙与两种屏幕方向的轨道为重新设计的原创关卡，完成后循环提高难度。本版重绘美术、音效与关卡参数，不包含原版全部关卡、配乐或资源文件。达标回撤 1.4 秒、标记珠在可见轨道存活 16 秒属于本版的手感调优，并非声称原版采用完全相同的数值。

## 手机操作

- 进入祖玛后直接使用独立游戏视口，暂停、换球和玩法按钮保持可触达。
- 按住棋盘瞄准，拖动调整，松手发射；轻点青蛙或换球按钮交换两颗珠。
- 横屏地图为 1280×650，竖屏为 900×1100。横屏收紧顶栏并使用浮动控制区，让彩珠有更大显示空间。
- 横竖切换保留珠链、弹丸、分数和生命。密集珠链可在入口外排队，避免为适配画面丢珠或突然进洞。
- 暂停、切到后台、回前台均保持游戏冻结，手动继续后才恢复计时。
- 新 APK 使用系统沉浸模式，用户仍可从屏幕边缘唤出系统栏；离开游戏恢复普通应用界面。

## 画面与性能

神庙背景、石蛙、骷髅入口、六色刻符珠、石刻 UI、蛤蟆装填三帧及独立骷髅下颚使用内置 imagegen 生成。资源放在 `assets/game-art/zuma/classic-v2/`，由 `art.zuma` 独立管理。现有首页祖玛图标保持不变。

背景与轨道只在画面尺寸、关卡或美术加载改变时重绘。普通和游戏模式在支持 WebGL 时使用解析球面法线光照、随珠链移动滚动的刻符纹理、弹丸拖尾、粒子爆散与扩张光波。珠体和光效合计两个 GPU 绘制批次，复用纹理和缓冲；游戏模式提高画布精度。省电模式使用缓存珠体纹理并减少粒子。遇到初始化失败、上下文丢失或连续高绘制耗时会退回 Canvas。游戏模拟采用固定 120 Hz 步长，显示帧率和画质模式不改变规则、移动速度或道具持续时间。

自动测试覆盖 10–120 Hz 时间一致性、首次碰撞、断口连锁、金币、穿隙、道具、通关、生命、两种方向、密集珠链与存档恢复。设备性能数字以验证报告为准；rAF 调度频率不等同于 GPU 实际呈现率或耗电量。

蛤蟆装填依次显示闭嘴、张嘴和吞咽帧，待发球在口腔遮罩内部显示。入洞后进入约 1.25–2.2 秒的加速吞噬阶段，骷髅下颚跟随吞球动作，珠链逐颗缩入洞内，整链吞完才扣一次生命。吞噬过程中暂停、切后台和续玩均保留该阶段。

## 存档与回退

新关卡的完整内部快照写入 `zumaClassic`，外层仍满足现有资源更新系统的存档版本 1。首次读取旧无尽局时保留累计分数和统计，重建第一座神庙。新版续玩保留关卡、弹丸、随机状态、道具计时与断口状态。

为了允许回退旧游戏包，外层另保存一份合法的旧轨道投影。回退后使用原来的无尽玩法；负距离排队珠和超过旧轨道容量的珠仅存在完整新快照中。若旧版继续游玩并重新保存，再更新新版会按旧局迁移保留最新分数，重新开始第一座神庙。这一过程不将新轨道坐标直接交给旧引擎。
